Preencha os blocos `describe` em `{spec_file}` para testar os métodos de `{service_file}`.
O arquivo `{service_file}` é SOMENTE LEITURA. Não altere o `beforeEach` do scaffold.

================================================================================
1. REGRAS NEGATIVAS MANDATÓRIAS (ANTI-PATTERNS PROIBIDOS)
================================================================================
- ❌ PROIBIDO: `service.metodo = jest.fn()` ou `jest.spyOn(service, ...)`. NUNCA mocke a própria classe/método sob teste (Princípio Anti-SUT de Khorikov). O método DEVE executar sua lógica real. Mocke apenas as dependências injetadas.
- ❌ PROIBIDO: Alterar ou sobrescrever o bloco `beforeEach` do scaffold determinístico.
- ❌ PROIBIDO: Chamar `.mockResolvedValue()` sem argumento em TypeScript estrito. Use SEMPRE `.mockResolvedValue(null)` ou `.mockResolvedValue([])`.
- ❌ PROIBIDO: Deixar blocos `describe` vazios sem testes `it(...)`.
- ❌ PROIBIDO: Instanciar manualmente todos os campos de DTOs ou entidades TypeORM complexas. Use SEMPRE `as any` em fixtures parciais (ex: `{{ id: '123' }} as any`).

================================================================================

3. MATRIZ DE CENÁRIOS DE TESTE OBRIGATÓRIOS
================================================================================
Para cada método público da classe, implemente múltiplos testes cobrindo os seguintes cenários:

A. Caminho de Sucesso (Happy Path)
```typescript
it('should return result when inputs are valid', async () => {{
  // Arrange: configure retorno esperado dos colaboradores
  repository.find.mockResolvedValueOnce([mockItem] as any);

  // Act: chame o método REAL do serviço
  const result = await service.metodo('param1');

  // Assert: verifique o retorno e a chamada à dependência
  expect(result).toBeDefined();
  expect(repository.find).toHaveBeenCalled();
}});
```

B. Consultas Encadeadas com QueryBuilder
```typescript
it('should query entities through queryBuilder with filters applied', async () => {{
  // Arrange: configure retorno pontual do QueryBuilder
  repository.createQueryBuilder().getMany.mockResolvedValueOnce([mockEntity] as any);

  // Act: chame o método do serviço
  const result = await service.metodoComQueryBuilder('filter-val');

  // Assert
  expect(repository.createQueryBuilder().where).toHaveBeenCalled();
  expect(result).toHaveLength(1);
}});
```

C. Branches Condicionais e Filtros (if/else, ternários e flags)
```typescript
it('should apply conditional filter when flag is true', async () => {{
  await service.metodo('value', true);
  expect(repository.createQueryBuilder().andWhere).toHaveBeenCalled();
}});

it('should bypass conditional filter when flag is false', async () => {{
  await service.metodo('value', false);
  expect(repository.createQueryBuilder().andWhere).not.toHaveBeenCalled();
}});
```

D. Casos Limite (Empty State / Not Found)
```typescript
it('should return empty collection when no records exist', async () => {{
  repository.find.mockResolvedValueOnce([]);
  const result = await service.metodo('param');
  expect(result).toEqual([]);
}});
```

E. Tratamento de Exceções (Sad Path)
```typescript
it('should throw exception when entity is not found', async () => {{
  repository.findOne.mockResolvedValueOnce(null);
  await expect(service.metodo('invalid-id')).rejects.toThrow();
}});

it('should propagate errors when dependency rejects', async () => {{
  repository.find.mockRejectedValueOnce(new Error('Database unavailable'));
  await expect(service.metodo('param')).rejects.toThrow('Database unavailable');
}});
```

4. GUIA ANTI-ERROS DE TYPESCRIPT (TYPEORM / BUILDERS / JEST)
================================================================================
Para garantir compilação nativa com zero erros de tipagem estrita (TS2345 / TS2339 / TS2352):

A. Fixtures de Entidades e Retornos Parciais
❌ ERRADO (gera TS2352 ou TS2345 por faltar colunas obrigatórias):
repository.findOne.mockResolvedValue({{ id: '123' }});

✅ CORRETO (Sempre use casting 'as any' no mock da fixture):
repository.findOne.mockResolvedValueOnce({{ id: '123' }} as any);

B. Customização Pontual de QueryBuilder
❌ ERRADO:
repository.createQueryBuilder = jest.fn(); // Destrói o encadeamento e métodos existentes

✅ CORRETO:
repository.createQueryBuilder().getOne.mockResolvedValueOnce({{ id: '123' }} as any);
repository.createQueryBuilder().getRawOne.mockResolvedValueOnce({{ total: '5' }});

C. Callbacks e Brackets (WhereExpressionBuilder)
✅ CORRETO:
Se precisar instanciar ou chamar diretamente o callback do Brackets em asserções:
brackets.whereFactory({{ andWhere: jest.fn() }} as any);
// OU
const mockQb: any = {{ andWhere: jest.fn() }};
brackets.whereFactory(mockQb as any);

D. Importação de Exceções NestJS
Se for validar instâncias de exceção específicas com `rejects.toThrow(NotFoundException)`:
Importe diretamente de `@nestjs/common`:
```typescript
import {{ NotFoundException, BadRequestException, ConflictException }} from '@nestjs/common';
```
